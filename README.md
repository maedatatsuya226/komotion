# こもーしょん (KOMOTION) 〜こもんじデジタルリハビリ〜

カメラで体の動きを検出し、画面を見ながらリーチ動作・バランス動作を訓練するリハビリアプリです。
脳卒中片麻痺・高齢者(転倒予防)・整形外科疾患の患者さんを想定しています。
名前は「こもんじ」+「モーション(動き)」の造語です。

## 収録ゲーム

| ゲーム | 訓練内容 | あそび方 |
|---|---|---|
| 🎈 バルーンポップ | 上肢リーチ | 画面に出る風船に手を伸ばして割る |
| 🍎 くだもの収穫 | リーチ＋運ぶ動作 | ぶら下がったくだものをつかみ、カゴまで運んで入れる |
| 🧺 キャッチバランス | バランス・重心移動(立位/座位) | 体を左右に傾けてカゴを動かし、落ちてくるものをキャッチ |
| 🐹 もぐらたたき | 反応スピード・交互リーチ | 穴から顔を出すもぐらを、消える前にすばやくタッチ |
| 🦋 ちょうちょ | リーチ位置の静的保持 | お花に手を伸ばして1〜3秒キープすると、ちょうちょがとまる |
| 🎨 いろタッチ | 二重課題(認知+運動) | 「あかをタッチ!」「3+4は?」の指示に従って正しい円をタッチ |

## 特徴

- **インストール不要**: ブラウザ(Chrome / Edge / Safari)で動くWebアプリ
- **プライバシー安全**: カメラ映像は端末内でのみ処理。外部への送信・保存は一切なし
- **ポーズ検出**: Google MediaPipe による骨格推定(初回のみモデルのダウンロードにネット接続が必要)

## 主な設定項目(ゲームごとに調整可)

| 項目 | 内容 |
|---|---|
| つかう手 | どちらでも / 右手だけ / 左手だけ / 指定ランダム(風船やくだものに「右」「左」の指定が出る) |
| 出る場所・カゴの場所 | 麻痺側だけに出す、カゴを患側に置いて体幹回旋を促す等に使用 |
| 大きさ | 大 / 中 / 小(小さいほど正確なリーチが必要) |
| スピード | 消える・落ちるまでの時間 |
| しせい | キャッチバランスのみ。立位 / 座位。座位を選ぶと案内文が座位向けになり、計測場所が「こし」の場合は自動で「かた」に切り替わる |
| うごきをはかる場所 | キャッチバランスのみ。こし(骨盤の側方移動)/ かた(体幹の傾き)/ あたま(頭部・姿勢全体)から選択。座位では「かた」か「あたま」を推奨 |
| キープ時間 | ちょうちょのみ。手を止めておく長さ(1〜3秒) |
| 課題のしゅるい | いろタッチのみ。いろ(色の指示)/ けいさん(足し算の答えを選ぶ) |
| からだを動かすはば | キャッチバランスのみ。大きめにすると、しっかり重心移動しないとカゴが動かない |
| トレーニング時間 | 1分 / 2分 / 3分 |

終了後に「成功数・出た数・成功率」が表示されます。

- **カメラズーム**: iPadの広角カメラでは患者さんが小さく映り、画面の端に手が届きにくくなります。
  「自動(おすすめ)」にすると、開始直後に患者さんの体の大きさ・立ち位置に合わせて一度だけ
  フレーミングし、合ったら固定します(訓練中に画面は動きません)。患者さんが大きく移動して
  ずれたままになったときだけ、一度合わせ直します(バランスゲーム中は完全固定)。
  倍率を手動で決めたい場合は「1.3倍〜2倍」を選んでください
- **介助者の立ち位置**: 画面には複数人が映っても「中央で大きく映っている人」を本人として追跡しますが、
  介助者はできるだけ患者さんの真後ろか、カメラの後ろに立つと誤検出がさらに減ります
- 設定はゲームごとに端末へ自動保存され、次回起動時も再現されます
- 患者さんがカメラの検出範囲から外れると、ゲームと残り時間は自動で一時停止します(戻ると再開)
- バランスの感度は肩幅を基準に自動調整されるため、カメラとの距離が多少変わっても同じ感覚で使えます
- 訓練中は画面が自動ロックされないようにしています(対応ブラウザのみ)

### キャッチバランスの基準位置

ゲーム開始時に「まっすぐ立って そのまま…」と表示されている間の姿勢が基準(まんなか)になります。
患者さんが正中位で静止してから計測が終わるのを待ってください(約2秒)。

## 動作テスト用デバッグモード

URLの末尾に `?debug` を付けると(例: `http://localhost:3789/?debug`)、カメラなしで
マウスカーソルを「右手」「重心」として全ゲームを動作確認できます。

## PCでの使い方

1. `起動する.bat` をダブルクリック(Node.jsが必要)
2. ブラウザが開いたら設定を選んで「スタート!」
3. カメラの使用許可を求められたら「許可」

※ `index.html` を直接ダブルクリックしてもカメラは起動しません(ブラウザのセキュリティ上、サーバー経由が必要です)。

## iPadでの使い方

iPadのSafariでカメラを使うには **HTTPS のURL** が必要です。以下のいずれかで無料公開できます:

- **GitHub Pages**: このフォルダをGitHubリポジトリにアップし、Pagesを有効化
- **Netlify Drop**: https://app.netlify.com/drop にこのフォルダをドラッグ&ドロップ

公開したURLをiPadのSafariで開けば、そのまま使えます。共有ボタン→「ホーム画面に追加」すると
「こもーしょん」の名前でアイコンが作られ、全画面のアプリとして起動できます。
テレビに映す場合は AirPlay または HDMI変換アダプタでミラーリングしてください。

## 訓練時のセッティングの目安

- **座位リーチ・座位バランス**: カメラ(iPad/PC)から約1〜1.5m。上半身が画面に入るように
- **立位リーチ・立位バランス**: カメラから約2〜3m。全身が画面に入るように
- 逆光を避け、患者さんの後ろに人が映り込まない場所で使用してください
- **転倒リスクのある方は必ず療法士が近位で見守り・介助できる位置で実施してください**
